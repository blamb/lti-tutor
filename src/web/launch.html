    Import from a Moodle course backup

    The course is read straight from Moodle through its web services, as it is right now: each unit's text, its activities and study questions, its pages, books and readings (including attached PDFs and Word files), its links, and each assignment with its due date and rubric. Nothing about people is read. Items imported before are refreshed in place; new ones are added. You review everything below before anything is saved.

    A backup brings the course in as it is: each unit's text, its activities and study questions, its pages, books and readings (including attached PDFs and Word files), its links, and each assignment with its due date and rubric. Nothing about people is read: no users, grades, submissions or forum posts. The file is deleted as soon as it has been read. You review everything below before anything is saved.

    How to make the backup in Moodle (about a minute)
    1. In your course, open More → Course reuse → Backup (in older Moodles: the gear menu → Backup).
    2. Untick Include enrolled users. The tool never uses user data, and the file is much smaller without it. Leave activities, blocks and files ticked.
    3. Click Jump to final step, then Continue when it finishes.
    4. In the Course backup area, click Download next to the newest file. It ends in .mbz.
    5. Choose that file below.

    Backups up to 150 MB are accepted. If yours is larger, make a backup without the course's video or audio files, or import the units you need by URL instead.

    Tick what to import. Each unit's short labels have been merged into one text material and one activities and study questions material; pages, readings and assignments are separate. Check the what it is column: it decides how the tutor uses each material, and a wrong guess is easy to fix here or later in the materials list. Items marked update were imported before and will be refreshed in place rather than added again.

    Moodle connection (live course sync)

    With a web-service token the tool can read this course straight from Moodle: a Sync from Moodle button on the materials tab brings in the units, readings, activities and assignments and refreshes them later with one click. The token is stored encrypted, only ever used to read, and can be revoked in Moodle at any time. It never touches users, grades, submissions or posts.

    How to get a token
    1. Your Moodle administrator enables web services and the REST protocol, and creates an external service (suggested name LTI Tutor course sync) that allows only the read functions listed below. Most sites already have web services on for the Moodle app.
    2. The administrator creates a token for your account on that service (Site administration → Server → Web services → Manage tokens → Create token), or, if they allow it, you create one yourself under Preferences → User account → Security keys.
    3. Paste the token here and click Connect. The tool checks who it belongs to, that the service allows what it needs, and that the account can read this course.
